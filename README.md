
# BloodConnect

Blood Donation Awareness and Emergency Blood Support System.

## Features
- Dashboard
- Donor Registration
- Emergency Blood Requests
- Find Potential Donors
- Track Requests
- Awareness Center
- Awareness Assistant
- Admin Dashboard

## Technologies
- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## Run the Application
Install dependencies:

pip install -r requirements.txt

Run the app:

streamlit run app.py

## Safety Notice
This is an educational prototype. For emergencies, contact a hospital or licensed blood bank.
